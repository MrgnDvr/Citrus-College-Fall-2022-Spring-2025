# Community College Projects 
Overview

This repository indexes my programming projects and coursework completed during my community college studies. The primary bulk of the assignments is coursework produced and assigned by Professor Robert Solis of Citrus College. 

The projects cover concepts and skills developed throughout that period. The main ones are programming fundamentals, data structures, algorithms, and an introduction to software development. 

Courses: 

CS 225 - Object-Oriented Programming - (Winter 2024)
Course Description: A community college-level course based on introducing the concepts of object-oriented programming in the context of the C++ language. (Find official course description online) 

CS 232 - Programming Concepts and Methodology (Data Structures and Algorithms) - (Fall 2024)
Course Description: A community college-level course based on implementing basic object-oriented concepts, introducing data structures and implementing basic algorithms. (Find official course description online)

CS 242 - Computer Architecture and Organization - (Spring 2025)
Course Description: A community college-level course introducing the nuances of computer architecture, operating in ARM x86, and effectively using the command line. (Find official course description online)
